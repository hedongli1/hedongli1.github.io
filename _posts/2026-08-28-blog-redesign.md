最近看着自己的[个人主页](https://hedongli1.github.io/)，越看越觉得哪里不对劲——背景倒是挺干净，但太"安静"了；而且首页一堆"TODO"占位文字，像个半成品。这周末我花时间把它收拾了一遍：**背景会动了，内容也填上了真材实料**。这篇文章就讲讲我改了啥、踩了哪些坑，全程说人话，不拽术语。

## 一、先说说问题出在哪

原来我的博客长这样：

1. **背景单调**：只有一层金色星云渐变 + 一点粒子连线，看久了像张静态壁纸，缺"活气"。
2. **内容全是占位**：关于我、技能、项目、经历，好几处写着 `TODO`、"项目一"、"项目二"，像个没写完的作业。
3. **项目卡太生硬**：实底黑卡片，在深色背景上显得突兀。

三个问题，我一个个解决。

## 二、背景怎么"动起来"的

最开始我想直接抄一个我很喜欢的作品集（lvhang）的背景——它的沉浸式星云特别炫。但扒开它的代码一看，**那背景是段视频**，不是几行 CSS 能搞定的。

我没视频素材，也不想给 GitHub Pages 塞几个 MB 的视频文件，于是换了条路：**用纯代码复刻那个感觉**。具体做了这么几层：

- **底层**：用 AI 生成了一张深色星云图垫底，再加 CSS 滤镜把颜色往黑金调（我博客的主色是金色）。
- **星点网格**：一行行细密的点阵，向四周渐渐隐去。
- **会转的轨道环**：几条椭圆轨道，金色光点拖着尾巴绕圈。
- **闪烁星星 + 金色尘埃 + 星芒**：星星会呼吸明灭，细小的光点慢慢往上飘，还有几颗带十字光芒的大星做焦点。
- **缓慢漂浮**：整张星云图以 36 秒一个周期缓缓移动缩放，像星空在漂。

这一套叠下来，背景就有了层次感——**明暗、大小、运动速度都不一样**，不再是死板的一张图。

## 三、内容怎么"填满"的

背景弄好后，转头把那些 TODO 全清掉了：

- **邮箱**、一句话定位、中英文简介，换成真实信息。
- **项目卡**：把我 GitHub 上四个真实仓库挂上去——[aiscan](https://github.com/hedongli1/aiscan)（零依赖代码安全审计工具）、[记账本](https://github.com/hedongli1/ledger-app)、[紫队实验台](https://github.com/hedongli1/purple-team-lab)、还有本站。
- **技能**：从前端 Vue、后端 Node/Express，到 Docker、GitHub Actions、SQLite，写我实际用过的东西。
- **经历**：四条真实时间线，对应四个项目的从零搭建过程。

每个项目卡还配了一张**黑金风格的预览图**（也是 AI 生成的，裁掉水印、压到几百 KB），卡片本身改成了半透明毛玻璃，hover 时图片会轻微放大——没那么突兀了。

## 四、踩过的几个坑

说几个实际遇到的问题，可能对你有用：

1. **"复刻背景"不等于"抄代码"**：人家的背景是视频，我没视频，硬抄行不通。最后是"借思路不借素材"——轨道环、网格、漂浮这些**手法**学过来，素材用代码自己画。
2. **AI 生成的图有水印**：Seedream 出的图右下角带"AI生成"小字，我直接用 PIL 裁掉底部一条再压缩，才敢往站里放。
3. **特效太淡 = 白做**：第一版我把网格线透明度设成 0.045、光点直径 1.5px，上线后**肉眼看不出差别**。后来把透明度提到 0.13、光点加到 3px 多、轨道线加粗，效果才出来。教训：**深色背景上，细节要大胆一点，别怕"太满"**。
4. **每次改动都留了回退点**：整个改造全程用 git 分支 + 分步提交，每改一版都单独 commit。这样哪一步不满意，一句 `git revert` 就能退回去，心里踏实。

## 五、最后说两句

这次改造最大的感受是：**"炫酷"不是堆料，是层次**。背景要好看，得让不同元素有不同的运动速度和明暗节奏；内容要好看，得把占位换成真实的东西——不然再炫的背景也救不回一个空架子。

如果你也想给自己的博客换背景，我的建议是：

- 先想清楚**主色**（我的是黑金），所有特效都围绕这个色走，别五颜六色。
- 深色背景上，**细节做足一点**，不然等于没做。
- **留好回退**，随时能撤，改起来才敢放手。
